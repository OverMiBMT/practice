## Установка
1. Скопируйте репозиторий:
- откройте терминал
- Введите:
```bash
git clone https://github.com/username/my-app.git
```
- Перейдите в папку:
```bash
cd my-app
```
2. Установите зависимости:
- python 3.10+
- pip
- SQLite
```bash
pip install -r requirements.txt
```
3. Запустите приложение
- Введите
```bash
python main.py
```
- Откройте браузер
- перейдите на 'localhost:8000'
